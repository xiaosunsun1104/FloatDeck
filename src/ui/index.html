使用说明

  1. 在左侧选择窗口，用网址左边的箭头选网站，或直接输入网址。
  2. 点击“打开网页”。拖动浮窗标题栏移动，拖动边缘调整大小。
  3. 点击“放大网页”可查看完整网站、账号和登录区域；完成后点击“返回浮窗”。这个按钮不表示账号已退出。
  4. 控制项随网站和页面变化。抖音推荐页支持上一条、下一条；没有视频时隐藏视频设置。可在下方展开快捷键设置。
  5. 设置改好后点击“保存设置”。鼠标移到左侧窗口项，末尾圆点变成叉号，点击即可关闭并移除。

账号与 Edge 分开保存在本机，正常重开和更新沿用原记录。每台电脑首次使用需自行登录；网站到期或安全验证可能要求重新登录。最小化主界面不会关闭浮窗，退出主程序会关闭全部浮窗。
