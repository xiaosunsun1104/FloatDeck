# 用户需求与验证边界

## 已确认

使用 Windows，把常用网页像副屏一样放在旁边，用于资料、聊天、监看页面状态或看视频。窗口按需添加，最多同时打开 10 个。

各个小窗都应保持可见，普通网页填满各自窗口，可自由拖动、手动缩放。地址框左侧提供常用网站下拉选项，允许手动输入其他网址；原有 A、B 设置兼容保留。有视频时再使用独立播放/暂停、前进、后退快捷键。

## 本地验证版的选择

用 Electron 独立置顶网页窗口代替浏览器原生 PiP，避免依赖 Edge 的原生多画中画能力。全局快捷键通过系统注册，始终按 A–J 编号路由，不使用模糊的最近播放目标。

这是先验证核心交互的桌面原型；它与“控制已有 Edge 标签页”的浏览器扩展方案不同。需要在真实视频验证后评估：独立应用带来的登录、资源开销是否可接受，还是改为扩展加本地辅助程序。

## 同类能力

- [Firefox](https://support.mozilla.org/en-US/kb/about-picture-picture-firefox) 已支持多个画中画窗口。
- [Global Speed](https://github.com/polywock/globalSpeed) 已提供多种视频快捷键及全局控制能力。
- [PiP Shortcut](https://github.com/corbindavenport/pip-shortcut) 已提供画中画及播放控制快捷键。

目前没有验证这些方案是否完整满足“Windows 游戏保持活动、两个不同网站视频、两组固定绑定、仅三个操作”的组合需求。不能把本项目宣传为首创或唯一方案；后续应实际比较配置成本、稳定性和资源占用。

## 验收清单

- [x] 左侧列出窗口，右侧仅显示选中窗口；切换时保留未保存的输入。
- [x] 移除宣传语、步骤条和重复保存按钮，快捷键可展开设置。
- [x] 键盘可上下切换窗口，说明可单独打开，小尺寸界面不横向溢出。
- [x] 左侧每项末尾默认显示圆点，悬停该项时显示叉号，点击直接关闭并移除；支持全部移除后重新添加。

- [x] 地址框左侧下拉菜单包含 10 个常用网站，选择只填入对应窗口的网址。
- [x] 支持自定义 HTTP/HTTPS 地址，裸域名自动补上 HTTPS。
- [x] 普通网页默认完整显示，没有视频时仍能使用页面。
- [x] 网页窗口可自由移动和手动缩放。

- [x] 界面可以添加 A–J 十个窗口项，达到上限后禁用添加。
- [x] 后端拒绝第 11 个窗口，已打开的窗口可关闭、移除设置并复用编号。
- [x] 10 个本地测试视频窗同时打开并置顶，每个都可独立暂停和跳转。
- [x] 30 个全局快捷键可注册，新增时避让已占用组合。
- [x] 原有 A、B 设置保留，10 窗口设置可以保存。

- [ ] A 为 B站、B 为抖音，两个视频能持续播放并保持置顶。
- [ ] 保持游戏为活动窗口，A 的三个按键仅影响 A。
- [ ] 保持游戏为活动窗口，B 的三个按键仅影响 B。
- [ ] A 暂停后，B 仍可继续播放和跳转，反向亦然。
- [ ] 跳转默认 5 秒，允许分别改为其他秒数。
- [ ] 快捷键修改、冲突提示、退出后释放符合预期。
- [ ] 抖音切换当前视频后，快捷键作用于新的视频。
- [ ] 当前游戏中没有持续掉帧或不可接受的资源占用。
- [ ] 10 路真实网页视频与游戏同时运行的性能达到可接受水平。

本地合成视频测试只能覆盖底层控制和窗口行为，以上真实场景需要逐项验证。

## 保持第一版范围

不添加下载、推荐、字幕翻译、自动识别攻略、账号导入和游戏内注入。鼠标穿透、控制现有 Edge 标签页不在本版范围内；只有用户需要时再扩展。

## 网站适配

- 抖音推荐页的上一条/下一条有独立快捷键，不在其他网站显示。
- 打开网页后检测实际视频与切换控件；普通页面隐藏视频设置，直播/不可跳转视频隐藏跳转按钮和秒数。
- 页面变化后同步更新界面和全局快捷键注册。
