# 0.4.0 界面调整与验证

## 参考

- [Windows NavigationView](https://learn.microsoft.com/en-us/windows/apps/develop/ui/controls/navigationview)：参考左侧导航与右侧内容的结构。
- [OBS Studio 官方界面](https://obsproject.com/kb/obs-studio-overview)：参考功能分组和统一的操作入口。

已实际查看两者官方截图。没有复制外部图标或素材，保留用户选定的 FloatDeck 图标。

## 调整

浅灰侧栏、白色内容区、少量蓝色强调。取消大标题宣传语、步骤条、并列大卡片和彩色编号块。左边按窗口编号和网站名列出，右边只显示一个窗口的地址及操作。右上角统一保存；快捷键设置默认折叠；帮助在左下角。普通网页功能、十窗口上限和独立视频控制不变，也未恢复已移除的“铺满屏幕”功能。

默认主界面 1040×760，最小 840×600。只调整主控制界面的大小，网页浮窗仍可手动移动、缩放。

## 验证

配置测试通过。桌面测试验证：切换窗口保留未保存的网址和跳转秒数，键盘上下切换，快捷键折叠状态保留，错误的隐藏字段会切换至对应窗口再提示，单一保存入口，帮助打开/关闭，以及小尺寸窗口不溢出。

原有网站预设、自定义网址、普通网页显示、10 个置顶窗口和 30 个独立快捷键注册等检查通过。已检查主界面、网站菜单、快捷键展开、小尺寸和 10 窗口列表的实际截图。

本轮没有重新验证外站登录和真实游戏性能。
