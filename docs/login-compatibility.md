# 登录兼容调整（版本保持 1.0）

用户在抖音登录时遇到“访问过多、系统繁忙”。尚未获取能证明具体原因的站点错误码，不能宣称此次调整已经解除网站端的限制。

本次修复了应用自身的兼容问题：

- 之前拒绝所有新窗口并把目标地址加载到原窗，会丢失 POST 提交语义、opener 回传和原页面上下文。现允许最多三个受控网页子窗口，继承同一登录会话并保持无 Node、隔离和沙箱；不允许文件/可执行协议。父窗关闭时清理子窗。
- 网页请求使用当前 Chromium 自身版本的桌面 User-Agent，移除应用名和 Electron 兼容标记；不伪造其他设备、修改指纹或关闭网站安全校验。
- 增加“网页登录 / 返回浮窗”。沿用同一窗口及会话，临时放大窗口，卸载视频辅助脚本，释放该窗视频快捷键；返回后恢复原大小和辅助控制。两次切换不刷新网页，不清理 Cookie。
- 对同一个已打开地址再次点击“打开网页”只显示当前窗口，避免反复重新加载登录页。

验证：12 项配置测试、桌面冒烟测试、本地登录流程测试通过。专用测试通过本地 HTTP 页验证 POST、opener 回传、共享 Cookie/会话、危险协议拦截、无 Node 访问及子窗口清理；桌面测试验证放大/恢复不刷新、脚本暂停与恢复、快捷键释放与恢复。未自动操作真实账号、验证码或登录界面，未重复请求抖音登录服务。

用户需在更新后点击“网页登录”，自行完成一次真实登录来确认。如仍返回“访问过多”，需要继续区分网站临时限制与内置浏览器兼容问题，不能用反复自动重试替代诊断。
