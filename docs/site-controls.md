# 网站控制适配（版本保持 1.0）

未打开时根据网址显示适用设置；打开后每秒检查实际页面能力。没有视频时隐藏视频控制；直播或不可跳转视频不显示跳转按钮、按键和秒数。抖音的上一条/下一条只在推荐页切换控件可用时显示。登录弹层遮挡控件时，隐藏并取消注册对应快捷键，关闭弹层后恢复。

旧的 A/B 地址、按键和秒数保留。抖音新增两组独立组合键，也允许自行修改。页面从其他网站跳转到抖音后，可以动态补充切换按键。所有按键仅对所属浮窗生效。

切换通过当前浮窗的 Chromium 输入通道点击页面切换按钮，不激活系统窗口，也不向游戏发送方向键。纯视频模式切换时短暂恢复网页布局以点击真实按钮，然后重新应用纯视频布局。

12 项配置/网站规则测试及桌面冒烟测试通过。桌面测试使用隔离网页验证切换、独立按键注册、弹层遮挡、跨站隐藏、直播停用跳转、普通网页隐藏设置和已有十窗口控制。真实抖音匿名页面弹出了登录层，完整的真实站点上一条/下一条往返测试尚未通过；仍需要关闭该弹层后在实际使用中确认，不能把本地夹具测试表述为真实站点验证成功。
