# 抖音延迟加载弹幕修复（版本保持 1.0）

用户确认缺失的是抖音弹幕。使用实际公开播放页检查旧代码，进入纯视频模式后 .danmu 才插入，原有全局 `body * { visibility:hidden }` 让它继承 hidden，随后“仅保留可见层”的过滤又将它排除；旧的扁平夹具未覆盖这个过程。

修复为只隐藏播放器外的兄弟分支，以及播放器内不含视频/弹幕的控件分支，不再全局隐藏播放器。弹幕层不按继承 visibility 过滤，延迟插入后也可显示；保留网站的显示/透明度、动画、字体和抖音弹幕区域高度设置。B站的特殊弹幕容器另做尺寸适配。

实际抖音公开播放页已见到纯视频模式顶部原生弹幕，截图为 test-artifacts/douyin-live-after.png；旧版检查记录为弹幕层存在但 visibility:hidden，新版为可见且有弹幕节点。B站实际播放页也已观察到原生弹幕。新增延迟插入层的离线回归用例通过，原生关闭状态、退出纯视频后的清理及原有十窗口检查通过。未使用真实账号或操作登录页。
