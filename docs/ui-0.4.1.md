# 0.4.1 侧栏关闭交互

右侧设置区不再显示“移除”。左侧每个窗口项的末尾平时显示原有状态圆点；鼠标移入该项时变为叉号，移出后恢复。关闭按钮有独立点击区域，不会触发窗口选择；键盘聚焦按钮时也会显示叉号。

点击叉号会关闭对应网页浮窗、释放它的快捷键并移除设置项。不要求预先关闭浮窗，也不保存其他项尚未保存的输入。关闭未选中的项不会切换当前选择。允许移除最后一项，空列表显示添加提示，之后可以重新添加并复用 A–J 编号。

验证通过：10 项配置测试和桌面冒烟测试。实际检查了圆点/叉号悬停前后的截图，并验证了已打开窗口的销毁、快捷键释放、其他输入保留、最后一项关闭后的焦点及空列表重新添加。原有 10 窗口、独立播放/跳转、网站选择与普通网页检查仍通过。
